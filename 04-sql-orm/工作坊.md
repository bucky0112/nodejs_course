# 工作坊：用 Drizzle 把 todo 存進 PostgreSQL

M1 的 todo 存在記憶體陣列，重啟就消失。這一章我們接上真正的資料庫。你會看到：Drizzle 產生的 SQL，就是你在 [S1] 手寫的那張表。

> 卡住了？對照 [`完成版/`](./完成版/)。

---

## 步驟 0：從 M1 接手、裝套件

把 [M1 完成版](../02-express-basics/完成版/) 複製一份當起點（或在你自己的 todo-app 上繼續），然後裝這章要用的套件：

```bash
npm install drizzle-orm pg dotenv
npm install -D drizzle-kit
```

- `drizzle-orm`：ORM 本體
- `pg`：PostgreSQL 的 Node.js 驅動
- `dotenv`：讀取 `.env` 裡的連線字串
- `drizzle-kit`（開發用）：產生與套用 migration 的工具

> 🧠 ORM 到底是什麼、為什麼選 Drizzle → [概念卡：ORM 是什麼](../concepts/orm-是什麼.md)

---

## 步驟 1：設定資料庫連線

建立資料庫，並把連線字串放進 `.env`：

```bash
createdb todo_app
```

`.env`（這個檔**不要進版控**，記得加進 `.gitignore`）：

```
DATABASE_URL=postgresql://使用者:密碼@localhost:5432/todo_app
```

> ✅ **檢查點 A**：套件裝好、`todo_app` 資料庫存在、`.env` 設定完成。

---

## 步驟 2：用 Drizzle 定義 schema

建立 `src/db/schema.js`：

```js
import { pgTable, integer, varchar, boolean, timestamp } from 'drizzle-orm/pg-core'

export const todos = pgTable('todos', {
  id: integer().generatedAlwaysAsIdentity().primaryKey(),
  title: varchar({ length: 200 }).notNull(),
  completed: boolean().notNull().default(false),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
})
```

對照你在 [S1] 寫的 `CREATE TABLE todos`——欄位完全一樣，只是換成 JavaScript 寫法。`generatedAlwaysAsIdentity()` 就對應 SQL 的 `GENERATED ALWAYS AS IDENTITY`。

---

## 步驟 3：建立 db client 與 drizzle 設定

`src/db/index.js`：

```js
import { drizzle } from 'drizzle-orm/node-postgres'
import pg from 'pg' // pg 是 CommonJS 套件，用 default 匯入再解構
import * as schema from './schema.js'

const { Pool } = pg
const pool = new Pool({ connectionString: process.env.DATABASE_URL })
export const db = drizzle(pool, { schema })
```

`drizzle.config.js`（給 drizzle-kit 用）：

```js
import 'dotenv/config'
import { defineConfig } from 'drizzle-kit'

export default defineConfig({
  out: './drizzle',
  schema: './src/db/schema.js',
  dialect: 'postgresql',
  dbCredentials: { url: process.env.DATABASE_URL },
})
```

> ✅ **檢查點 B**：schema、db client、drizzle 設定都建好了。

---

## 步驟 4：產生並套用 migration

在 `package.json` 的 `scripts` 加上：

```json
"generate": "drizzle-kit generate",
"migrate": "drizzle-kit migrate",
"studio": "drizzle-kit studio"
```

然後：

```bash
npm run generate    # 比對 schema，產生 SQL migration 到 drizzle/
npm run migrate     # 把 migration 套用到資料庫
```

打開 `drizzle/0000_xxx.sql` 看一眼——**這就是你在 S1 手寫的 SQL**，Drizzle 幫你產生的。

> 🧠 generate / migrate / push 差在哪、什麼時候用哪個 → [概念卡：Drizzle Migration](../concepts/drizzle-migration.md)
>
> ✅ **檢查點 C**：資料庫裡有了 `todos` 表（可用 `npm run studio` 或 `psql -d todo_app -c '\d todos'` 確認）。

## 步驟 5：把路由從「陣列」改成「Drizzle 查詢」

在 `app.js` 頂部載入：

```js
import 'dotenv/config'
import express from 'express'
import { eq, asc } from 'drizzle-orm'
import { db } from './src/db/index.js'
import { todos } from './src/db/schema.js'
```

刪掉記憶體陣列 `let todos = [...]`，把五個路由改成 async + Drizzle：

```js
// 取得全部
app.get('/todos', async (req, res) => {
  const all = await db.select().from(todos).orderBy(asc(todos.id))
  res.json(all)
})

// 新增
app.post('/todos', async (req, res) => {
  const { title } = req.body
  if (typeof title !== 'string' || title.trim() === '') {
    return res.status(400).json({ error: 'title 必填，且必須是非空字串' })
  }
  const [todo] = await db.insert(todos).values({ title: title.trim() }).returning()
  res.status(201).json(todo)
})

// 部分更新
app.patch('/todos/:id', async (req, res) => {
  const id = Number(req.params.id)
  const { title, completed } = req.body
  const fields = {}
  if (title !== undefined) {
    if (typeof title !== 'string' || title.trim() === '') {
      return res.status(400).json({ error: 'title 必須是非空字串' })
    }
    fields.title = title.trim()
  }
  if (completed !== undefined) {
    if (typeof completed !== 'boolean') {
      return res.status(400).json({ error: 'completed 必須是布林值' })
    }
    fields.completed = completed
  }
  if (Object.keys(fields).length === 0) {
    return res.status(400).json({ error: '沒有提供要更新的欄位' })
  }
  const [todo] = await db.update(todos).set(fields).where(eq(todos.id, id)).returning()
  if (!todo) return res.status(404).json({ error: '找不到這筆 todo' })
  res.json(todo)
})
```

（`GET /todos/:id` 與 `DELETE` 同理，見 [完成版 app.js](./完成版/app.js)。）

三個要點：

- `await db.select().from(todos)` 對應 `SELECT * FROM todos`——Drizzle API 幾乎一對一映射 SQL。
- `.returning()` 讓 insert/update/delete 回傳被影響的列（PostgreSQL 的 `RETURNING`）。
- 路由全變成 `async`，但**不用包 try/catch**——Express 5 會自動把 reject 的錯誤轉交給錯誤處理 middleware。
  > 🧠 [概念卡：Express 的錯誤處理 § Express 5 的 async 自動轉交](../concepts/express-錯誤處理.md)

## 步驟 6：驗證資料真的存下來了

```bash
npm run dev
# 新增幾筆 todo
curl -X POST localhost:3000/todos -H 'Content-Type: application/json' -d '{"title":"買牛奶"}'
# 按 Ctrl+C 停掉伺服器，再 npm run dev 重啟
curl localhost:3000/todos    # ← 剛剛那筆還在！
```

重啟後資料還在，這就是「接資料庫」的意義。
