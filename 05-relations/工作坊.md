# 工作坊：幫 todo 加上清單(1:N) 與標籤(M:N)

M2 的 todo 是一張平的清單。這一章我們加上兩種關聯：todo 歸到「清單」（一對多），todo 貼「標籤」（多對多）。這正是 [S1] 用 SQL 做過的事，現在改用 Drizzle。

> 卡住了？對照 [`完成版/`](./完成版/)。

---

## 步驟 1：擴充 schema

在 `src/db/schema.js` 加入三張表，並在 todos 加上 `listId` 外鍵：

```js
import { pgTable, integer, varchar, boolean, timestamp, primaryKey } from 'drizzle-orm/pg-core'
import { relations } from 'drizzle-orm'

// 清單（1:N 的「一」邊）
export const lists = pgTable('lists', {
  id: integer().generatedAlwaysAsIdentity().primaryKey(),
  name: varchar({ length: 100 }).notNull(),
})

// todos 多了 listId 外鍵
export const todos = pgTable('todos', {
  id: integer().generatedAlwaysAsIdentity().primaryKey(),
  title: varchar({ length: 200 }).notNull(),
  completed: boolean().notNull().default(false),
  listId: integer('list_id').references(() => lists.id, { onDelete: 'set null' }),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
})

export const tags = pgTable('tags', {
  id: integer().generatedAlwaysAsIdentity().primaryKey(),
  name: varchar({ length: 50 }).notNull().unique(),
})

// 中介表（M:N），複合主鍵
export const todoTags = pgTable(
  'todo_tags',
  {
    todoId: integer('todo_id').notNull().references(() => todos.id, { onDelete: 'cascade' }),
    tagId: integer('tag_id').notNull().references(() => tags.id, { onDelete: 'cascade' }),
  },
  (t) => [primaryKey({ columns: [t.todoId, t.tagId] })],
)
```

> 🧠 為什麼 1:N 外鍵放在「多」邊、M:N 要中介表 → [概念卡：SQL 關聯與 JOIN](../concepts/sql-關聯與join.md)
>
> ✅ **檢查點 A**：四張表（含中介表）都定義好了。

## 步驟 2：定義 relations，產生 migration

接在 schema 後面，告訴 Drizzle 表跟表怎麼連（這樣才能用 Query API 撈關聯）：

```js
export const listsRelations = relations(lists, ({ many }) => ({
  todos: many(todos),
}))

export const todosRelations = relations(todos, ({ one, many }) => ({
  list: one(lists, { fields: [todos.listId], references: [lists.id] }),
  todoTags: many(todoTags),
}))

export const tagsRelations = relations(tags, ({ many }) => ({
  todoTags: many(todoTags),
}))

export const todoTagsRelations = relations(todoTags, ({ one }) => ({
  todo: one(todos, { fields: [todoTags.todoId], references: [todos.id] }),
  tag: one(tags, { fields: [todoTags.tagId], references: [tags.id] }),
}))
```

產生並套用 migration：

```bash
npm run generate
npm run migrate
```

> 🧠 relations() 與 Query API 怎麼運作 → [概念卡：Drizzle 的關聯查詢](../concepts/drizzle-關聯查詢.md)
>
> ✅ **檢查點 B**：資料庫多了 lists、tags、todo_tags 三張表，todos 多了 list_id。

## 步驟 3：清單與標籤的路由

加入基本的建立 / 列出：

```js
import { eq, and, asc } from 'drizzle-orm'
import { todos, lists, tags, todoTags } from './src/db/schema.js'

app.get('/lists', async (req, res) => {
  res.json(await db.select().from(lists).orderBy(asc(lists.id)))
})
app.post('/lists', async (req, res) => {
  const { name } = req.body
  if (typeof name !== 'string' || name.trim() === '') {
    return res.status(400).json({ error: 'name 必填' })
  }
  const [list] = await db.insert(lists).values({ name: name.trim() }).returning()
  res.status(201).json(list)
})

// tags 同理（見完成版）
```

並讓 `POST /todos` 能接受 `listId`（記得驗證該清單存在）：

```js
if (listId !== undefined && listId !== null) {
```

## 步驟 4：貼/撕標籤，用 Query API 撈關聯

**貼標籤**（在中介表新增一列）：

```js
app.post('/todos/:id/tags', async (req, res) => {
  const todoId = Number(req.params.id)
  const { tagId } = req.body
  const todo = await db.query.todos.findFirst({ where: eq(todos.id, todoId) })
  if (!todo) return res.status(404).json({ error: '找不到這筆 todo' })
  const tag = await db.query.tags.findFirst({ where: eq(tags.id, Number(tagId)) })
  if (!tag) return res.status(404).json({ error: '找不到這個標籤' })

  await db.insert(todoTags).values({ todoId, tagId: Number(tagId) }).onConflictDoNothing()
  res.status(201).json({ todoId, tagId: Number(tagId) })
})
```

**撕標籤**——⚠️ 中介表是複合主鍵，刪除時**兩個欄位都要比對**，否則會誤刪整個 todo 的所有標籤：

```js
app.delete('/todos/:id/tags/:tagId', async (req, res) => {
  const todoId = Number(req.params.id)
  const tagId = Number(req.params.tagId)
  const [removed] = await db
    .delete(todoTags)
    .where(and(eq(todoTags.todoId, todoId), eq(todoTags.tagId, tagId)))   // ← 兩個都比對
    .returning()
  if (!removed) return res.status(404).json({ error: '這個 todo 沒有這個標籤' })
  res.status(204).send()
})
```

**撈關聯**——讓 `GET /todos` 帶出清單與標籤：

```js
function shapeTodo(todo) {
  const { todoTags: links, ...rest } = todo
  return { ...rest, tags: (links ?? []).map((l) => l.tag) }   // 把標籤攤平成乾淨陣列
}

app.get('/todos', async (req, res) => {
  const rows = await db.query.todos.findMany({
    with: { list: true, todoTags: { with: { tag: true } } },
    orderBy: asc(todos.id),
  })
  res.json(rows.map(shapeTodo))
})
```

測試：

```bash
curl -X POST localhost:3000/lists -d '{"name":"工作"}' -H 'Content-Type: application/json'
curl -X POST localhost:3000/tags  -d '{"name":"緊急"}' -H 'Content-Type: application/json'
curl -X POST localhost:3000/todos -d '{"title":"寫週報","listId":1}' -H 'Content-Type: application/json'
curl -X POST localhost:3000/todos/1/tags -d '{"tagId":1}' -H 'Content-Type: application/json'
curl localhost:3000/todos   # ← 每筆 todo 帶 list 物件與 tags 陣列
```
