# 課堂練習：自己寫一個模組，接進原生 http 伺服器

> 這不是工作坊的延伸，而是**把這堂的核心重點再走一遍**，但這次沒有逐步指引，你得自己寫。
>
> 核心重點：用 `export` / `import` 把功能拆到別的檔案；用原生 `http` 依照 `req.url` 回不同的 JSON 與狀態碼。

工作坊帶你做了 `math.js` 和一個 todo 伺服器。現在你要從一個空資料夾開始，自己做一個「名言佳句」小服務。

---

## 任務

新建資料夾 `quotes-practice/`，裡面要有：

**1. `package.json`**：用 `npm init -y` 產生，並設定成 ESM。

**2. `quotes.js`**（資料與工具函式模組）：

- 具名匯出一個陣列 `quotes`，至少三筆，每筆形狀如下：

  ```js
  { id: 1, text: '先求有，再求好', author: '佚名' }
  ```

- 具名匯出函式 `findQuote(id)`：找到回傳該筆，找不到回傳 `undefined`。
- 預設匯出函式 `randomQuote()`：隨機回傳一筆。

**3. `server.js`**（原生 http 伺服器）：從 `quotes.js` 匯入上面三樣東西，提供這些路徑：

| 路徑 | 回應 | 狀態碼 |
|---|---|---|
| `/quotes` | 全部名言 | 200 |
| `/quotes/random` | 隨機一筆 | 200 |
| `/quotes/1`、`/quotes/2`…… | 對應的那一筆 | 200 |
| `/quotes/999` | `{ "error": "找不到這則名言" }` | 404 |
| 其他路徑 | `{ "error": "找不到頁面" }` | 404 |

**明確規格**（這幾條就是這堂重點，別漏）：

- `package.json` 要有 `"type": "module"`，全程用 `import` / `export`，不准出現 `require`。
- import 路徑要寫完整副檔名（`./quotes.js`）。
- `quotes.js` 同時要有**具名匯出**和**預設匯出**，`server.js` 兩種都要匯入。
- 每個回應都要設 `Content-Type: application/json`。
- `/quotes/:id` 的 id 從 `req.url` 自己切出來，記得轉成數字再比對。

> 💡 卡在「預設匯出和具名匯出怎麼一起 import」時，回去翻[概念卡：ESM vs CommonJS](../concepts/esm-vs-cjs.md)。不要翻工作坊的 `modules-main.js` 照抄：憑記憶寫，寫不出來才回去看，這樣才練得到。

---

## 進階（行有餘力）

- 加一個 `package.json` 的 script，讓 `npm run dev` 用 `node --watch server.js` 啟動。
- 支援 `/quotes?author=佚名` 只回傳該作者的名言（提示：用 `new URL(req.url, 'http://localhost')` 拿 `searchParams`）。

---

## 自我檢核

```bash
node server.js
curl localhost:3000/quotes
curl localhost:3000/quotes/random
curl localhost:3000/quotes/1
curl -i localhost:3000/quotes/999   # -i 會印出狀態碼
curl -i localhost:3000/nope
```

- [ ] 1. `package.json` 有 `"type": "module"`，整個資料夾找不到 `require`
- [ ] 2. `/quotes` 回傳全部、`/quotes/random` 每次可能不同
- [ ] 3. `/quotes/1` 回傳第一筆，`/quotes/999` 回 404 與錯誤 JSON
- [ ] 4. 亂打路徑回 404
- [ ] 5. 每個回應的 `Content-Type` 都是 `application/json`（用 `curl -i` 看）
