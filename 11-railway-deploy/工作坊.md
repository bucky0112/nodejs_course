# 工作坊：把 todo app 部署到 Railway

把你一路建起來的 todo app 送上線。Railway 會自動偵測 Node 專案來建置，你不必寫 Dockerfile。

> 需要 Railway 帳號。完成版的 `railway.json` 在 [`完成版/`](./完成版/)。

---

## 步驟 1：確認程式部署就緒

你的 todo app 其實已經準備好了，檢查三件事：

```js
// 1. 聽平台給的 port（不要寫死 3000）
const PORT = process.env.PORT || 3000
app.listen(PORT, ...)
```

```json
// 2. package.json 有 start script
"scripts": { "start": "node app.js", "migrate": "drizzle-kit migrate" }
```

```
// 3. .gitignore 有 .env（祕密不進版控）
node_modules/
.env
```

> 🧠 為什麼要這樣 → [概念卡：部署——環境變數與正式設定](../concepts/部署-環境變數與正式設定.md)
>
> ✅ **檢查點 A**：三項都符合。

---

## 步驟 2：在 Railway 建專案、加 PostgreSQL

1. [Railway](https://railway.app/) → New Project → Deploy from GitHub repo（選你的 todo app repo）。
2. 在專案裡 **New → Database → PostgreSQL**。Railway 會自動建一個 Postgres，並提供一個 `DATABASE_URL` 變數。

> ✅ **檢查點 B**：專案建好、PostgreSQL 已加入。

---

## 步驟 3：設環境變數、讓 migration 自動跑

1. 在你的服務的 **Variables** 設定：
   - `DATABASE_URL`：引用 Railway Postgres 的（通常用 `${{Postgres.DATABASE_URL}}` 參照）
   - `JWT_SECRET`、`GOOGLE_*`、`AWS_*` 等你用到的祕密
2. 讓 migration 在每次部署前自動執行——在專案根目錄放 `railway.json`：

```json
{
  "$schema": "https://railway.com/railway.schema.json",
  "build": { "builder": "NIXPACKS" },
  "deploy": {
    "startCommand": "npm start",
    "preDeployCommand": "npm run migrate"
  }
}
```

> ✅ **檢查點 C**：變數設好、`railway.json` 就位。

---

## 步驟 4：部署、拿網址、測試

push 到 GitHub（或 `railway up`）觸發部署。完成後在 **Settings → Networking** 產生一個公開網址。

```bash
# 用你的 Railway 網址測（先註冊拿 token）
curl -X POST https://你的app.up.railway.app/auth/register \
  -H 'Content-Type: application/json' -d '{"username":"alice","password":"secret123"}'
```

看部署 log，應該看得到 `npm run migrate` 有跑、伺服器有啟動。

> ✅ **檢查點 D（完成版）**：線上網址能註冊、登入、操作 todo，資料存進 Railway 的 PostgreSQL。

---
