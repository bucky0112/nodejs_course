# 工作坊：會員頭像上傳到 S3

這章讓會員上傳頭像。檔案不存自己的伺服器，而是放到 AWS S3，並用安全的方式取回。

> 卡住了？對照 [`完成版/`](./完成版/)。需要 AWS 帳號才能跑到真正上傳那步。

---

## 步驟 0：建 bucket 與 IAM（最小權限）

1. AWS Console → S3 → 建立一個 **私有** bucket（保留「封鎖所有公開存取」）。
2. IAM → 建立使用者 → 只給這個 bucket 的最小權限政策：

```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["s3:PutObject", "s3:GetObject"],
    "Resource": "arn:aws:s3:::你的-bucket/*"
  }]
}
```

3. 拿到 Access Key / Secret，連同 region、bucket 名稱填進 `.env`。

> 🧠 為什麼不要給 FullAccess → [概念卡：S3 與 Presigned URL § IAM 最小權限](../concepts/s3-presigned-url.md)
>
> ✅ **檢查點 A**：bucket、IAM、.env 就緒。

## 步驟 1：schema 加 avatarKey，設定 multer

users 加一欄存 S3 的 object key：

```js
avatarKey: varchar('avatar_key', { length: 255 }),   // 存 key，不是公開網址
```

`npm run generate && npm run migrate`。

```bash
npm install multer @aws-sdk/client-s3 @aws-sdk/s3-request-presigner
```

設定 multer（記憶體儲存 + 型別/大小限制）：

```js
import multer from 'multer'

const upload = multer({
  storage: multer.memoryStorage(),
  limits: { fileSize: 2 * 1024 * 1024 },          // 2MB
  fileFilter: (req, file, cb) => {
    if (!file.mimetype.startsWith('image/')) return cb(new Error('只接受圖片檔'))
    cb(null, true)
  },
})
```

> 🧠 為什麼用 memoryStorage、mimetype 為何不可全信 → [概念卡：用 multer 處理檔案上傳](../concepts/檔案上傳-multer.md)
>
> ✅ **檢查點 B**：multer 設定好。

## 步驟 2：上傳路由——驗證後串流上 S3

```js
import crypto from 'node:crypto'
import path from 'node:path'
import { PutObjectCommand } from '@aws-sdk/client-s3'
import { s3, BUCKET } from './src/config/s3.js'

app.post('/me/avatar', requireAuth, upload.single('avatar'), async (req, res) => {
  if (!req.file) return res.status(400).json({ error: '請上傳一張圖片（欄位名 avatar）' })

  // 用隨機檔名，不信任使用者原始檔名
  const ext = path.extname(req.file.originalname).toLowerCase() || '.img'
  const key = `avatars/${req.userId}/${crypto.randomUUID()}${ext}`

  await s3.send(new PutObjectCommand({
    Bucket: BUCKET,
    Key: key,
    Body: req.file.buffer,            // memoryStorage 的 buffer，直接上傳
    ContentType: req.file.mimetype,
  }))

  await db.update(users).set({ avatarKey: key }).where(eq(users.id, req.userId))
  res.status(201).json({ avatarKey: key })
})
```

別忘了在錯誤處理 middleware 接住 multer 的大小超限：

```js
if (err instanceof multer.MulterError && err.code === 'LIMIT_FILE_SIZE') {
  return res.status(413).json({ error: '檔案太大（上限 2MB）' })
}
```

> ✅ **檢查點 C**：上傳合法圖片成功；非圖片回 400、超大檔回 413。

## 步驟 3：用 presigned URL 取回頭像

bucket 是私有的，不能直接給公開網址。改成後端臨時簽一個短期 URL：

```js
import { GetObjectCommand } from '@aws-sdk/client-s3'
import { getSignedUrl } from '@aws-sdk/s3-request-presigner'

app.get('/me/avatar', requireAuth, async (req, res) => {
  const user = await db.query.users.findFirst({ where: eq(users.id, req.userId) })
  if (!user?.avatarKey) return res.status(404).json({ error: '還沒有上傳頭像' })

  const url = await getSignedUrl(
    s3,
    new GetObjectCommand({ Bucket: BUCKET, Key: user.avatarKey }),
    { expiresIn: 300 },   // 5 分鐘
  )
  res.json({ url })
})
```

前端拿這個 `url` 當 `<img src>` 即可，過期再要新的。

> 🧠 為什麼用 presigned URL 而不是公開 bucket → [概念卡：S3 與 Presigned URL](../concepts/s3-presigned-url.md)
>
> ✅ **檢查點 D（完成版）**：能上傳、能用 presigned URL 取回頭像。
