# 工作坊：把 Node.js 基本功跑過一遍

這一章我們不寫 todo app，而是把後面每一章都會用到的 Node 基本功——模組、非同步、內建模組——各自動手跑一遍，最後用**原生 http** 做一個極簡伺服器，當作 [M1 Express] 的對照組。

## 步驟 0：認識 Node.js

Node.js 是一個**基於 Chrome V8 引擎的 JavaScript 執行環境**——簡單說，它讓 JavaScript 不只能跑在瀏覽器，也能跑在你的電腦／伺服器上，去操作檔案、開網路伺服器、連資料庫。

| | 瀏覽器 JS | Node.js |
|---|---|---|
| 環境 | 瀏覽器 | 作業系統 / 伺服器 |
| 能做什麼 | 操作 DOM、BOM | 讀寫檔案、開伺服器、連 DB |
| 獨有物件/模組 | `window`、`document` | `fs`、`http`、`path` |

前端工程師為什麼要學？因為 npm 是世界上最大的開源套件庫，而且懂後端怎麼運作，前後端協作會順很多。

## 步驟 1：用 nvm 裝 Node 22，玩 REPL

直接到官網下載也行，但建議用 **nvm**（Node Version Manager）管理版本——不同專案常要不同 Node 版本。

```bash
# 安裝最新 LTS（目前是 Node 22）
nvm install --lts

# 指定本課程版本
nvm install 22
nvm use 22

# 確認
node -v   # 應該看到 v22.x
```

裝好後，在終端機輸入 `node` 進入 **REPL**（Read-Eval-Print-Loop，邊打邊執行）：

```bash
> 2 + 2
4
> const name = 'Node'
undefined
> `Hello, ${name}`
'Hello, Node'
```

打 `.exit` 或按兩次 `Ctrl+C` 離開。

> ✅ **檢查點 A**：`node -v` 顯示 v22.x，REPL 進得去也出得來。

## 步驟 2：建立第一個專案，設成 ESM

```bash
mkdir node-basics && cd node-basics
npm init -y
```

這會生出一個 `package.json`。打開它，加上 `"type": "module"`——這樣才能用現代的 `import`/`export` 語法（本課程全程用 ESM）：

```json
{
  "name": "node-basics",
  "type": "module"
}
```

> 🧠 為什麼要設這行、ESM 和舊的 CommonJS（`require`）差在哪 → [概念卡：ESM vs CommonJS](../concepts/esm-vs-cjs.md)

## 步驟 3：用 npm 裝一個套件

npm 是 Node 的套件管理工具。隨便裝個玩具套件感受一下：

```bash
npm install cowsay
```

裝完看 `package.json`，會多出 `dependencies`，而且生出一個 `node_modules/` 資料夾（裡面是套件本體，**不要 commit**，所以實務上會用 `.gitignore` 擋掉）。

`package.json` 幾個關鍵欄位：

```json
{
  "name": "專案名稱",
  "version": "1.0.0",
  "type": "module",
  "scripts": { "start": "node index.js" },
  "dependencies": { "cowsay": "^1.6.0" }
}
```

- `scripts`：自訂指令，用 `npm run <name>` 執行。
- `dependencies`：跑起來需要的套件。
- `^1.6.0` 的 `^`：允許更新到相容的小版本。

> ✅ **檢查點 B**：`package.json` 有 `"type": "module"`，且 `npm install` 後出現 `node_modules/`。

## 步驟 4：自己寫一個模組

模組就是「把功能拆到別的檔案，再 import 進來用」。建立 `math.js`：

```js
export const add = (a, b) => a + b
export const subtract = (a, b) => a - b

// 預設匯出：這個檔案的「主角」
export default function greet(name) {
  return `Hello, ${name}!`
}
```

建立 `modules-main.js` 把它用起來：

```js
// 具名匯入用大括號；預設匯出可以自己取名字
import greet, { add, subtract } from './math.js'

console.log(add(5, 3)) // 8
console.log(subtract(5, 3)) // 2
console.log(greet('Node')) // Hello, Node!
```

執行：

```bash
node modules-main.js
```

> 💡 注意 import 路徑要寫**完整副檔名** `./math.js`——這是 ESM 的規定，跟舊的 CommonJS 可以省略 `.js` 不一樣。

> ✅ **檢查點 C**：印出 `8` / `2` / `Hello, Node!`。

## 步驟 5：同步 vs 非同步

Node 是單執行緒的，碰到「要等」的事（讀檔、查 DB）的處理方式，是這門課的核心直覺。先準備兩個檔案：

```bash
echo "這是檔案 1 的內容。" > file1.txt
echo "這是檔案 2 的內容。" > file2.txt
```

**同步版** `sync.js`——會卡住，一個讀完才讀下一個：

```js
import fs from 'node:fs'

console.log('--- 同步開始 ---')
console.time('同步總耗時')
fs.readFileSync('file1.txt', 'utf8')
console.log('讀取檔案 1 完成')
fs.readFileSync('file2.txt', 'utf8')
console.log('讀取檔案 2 完成')
console.log('這句話必須等上面都讀完才會出現')
console.timeEnd('同步總耗時')
```

**非同步版** `async.js`——發出請求就先走：

```js
import fs from 'node:fs/promises'

async function asyncDemo() {
  console.log('--- 非同步開始 ---')
  console.time('非同步總耗時')

  const p1 = fs.readFile('file1.txt', 'utf8').then(() => console.log('非同步：檔案 1 完成'))
  const p2 = fs.readFile('file2.txt', 'utf8').then(() => console.log('非同步：檔案 2 完成'))

  console.log('當檔案還在讀取時，我已經執行到這行了！')
  await Promise.all([p1, p2])
  console.timeEnd('非同步總耗時')
}

asyncDemo()
```

各跑一次，注意 console 印出的**順序**：

```bash
node sync.js
node async.js
```

非同步版裡，「我已經執行到這行了」會**早於**「檔案完成」出現——這就是非同步的精髓。

> 🧠 callback / Promise / async-await 三代寫法、為什麼單執行緒還能撐高併發 → [概念卡：Node.js 的非同步機制](../concepts/非同步機制.md)

> ✅ **檢查點 D**：非同步版的「執行到這行」印在「檔案完成」之前。

## 步驟 6：內建模組 path / url（含 `__dirname` 正解）

Node 內建一堆好用模組，不用 npm 裝。建立 `builtins.js`：

```js
import path from 'node:path'

// ⚠️ ESM 裡沒有 __dirname！要用 import.meta.dirname（Node 20.11+ / 22 內建）
const here = import.meta.dirname

const fullPath = path.join(here, 'files', 'test.txt')
console.log('完整路徑:', fullPath)
console.log('檔名:', path.basename(fullPath)) // test.txt
console.log('副檔名:', path.extname(fullPath)) // .txt

const myUrl = new URL('https://example.com/path?name=test&age=25')
console.log('hostname:', myUrl.hostname)
console.log('查詢參數 name:', myUrl.searchParams.get('name'))
```

```bash
node builtins.js
```

> ⚠️ 這是 S0 舊講義最大的坑：很多文章在 ESM 裡寫 `path.join(__dirname, ...)`，一跑就 `ReferenceError: __dirname is not defined`。Node 22 的正解是 `import.meta.dirname`。
>
> 🧠 為什麼 ESM 沒有 `__dirname`、舊 Node 怎麼補 → [概念卡：ESM vs CommonJS](../concepts/esm-vs-cjs.md)

> ✅ **檢查點 E**：印出路徑資訊，且**不報** `__dirname is not defined`。

## 步驟 7：原生 http 做一個極簡 todo 伺服器

最後，用 Node 內建的 `http` 模組開一個伺服器。建立 `server.js`：

```js
import http from 'node:http'

const todos = ['學習 Node.js', '認識 HTTP 模組', '完成 S0']

const server = http.createServer((req, res) => {
  res.setHeader('Content-Type', 'application/json')

  if (req.url === '/health') {
    res.writeHead(200)
    res.end(JSON.stringify({ status: 'success', message: 'OK' }))
  } else if (req.url === '/todos') {
    res.writeHead(200)
    res.end(JSON.stringify({ status: 'success', data: todos }))
  } else if (req.url === '/todos/count') {
    res.writeHead(200)
    res.end(JSON.stringify({ status: 'success', count: todos.length }))
  } else {
    res.writeHead(404)
    res.end(JSON.stringify({ status: 'error', message: '找不到頁面' }))
  }
})

const PORT = process.env.PORT || 3000
server.listen(PORT, () => {
  console.log(`伺服器運行在 http://localhost:${PORT}/`)
})
```

```bash
node server.js
```

開另一個終端機測：

```bash
curl localhost:3000/todos
curl localhost:3000/todos/count
curl localhost:3000/health
curl localhost:3000/nope     # 404
```

**感受一下**：每加一條路由，就要多寫一個 `else if`；要解析 query string、處理 POST body、回正確狀態碼，全都得自己手刻。這很快會失控——所以下一章我們換成 **Express**，它把這些瑣事都包好了。

> ✅ **檢查點 F**：四個 curl 各自回傳正確 JSON，亂打路徑回 404。
