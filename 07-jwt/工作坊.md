# 工作坊：把認證從 Session 換成 JWT

M4 用 session（伺服器存狀態）。這章換成 JWT：伺服器不存任何東西，登入時發一個 token，之後請求帶著它就行。

> 卡住了？對照 [`完成版/`](./完成版/)。schema 與 M4 相同，這章只改認證部分。

---

## 步驟 1：移除 session，登入改發 token

```bash
npm uninstall express-session
npm install jsonwebtoken
```

`.env` 把 `SESSION_SECRET` 換成 `JWT_SECRET`（一樣用隨機字串）。

在 `app.js` 移除 `session(...)` middleware，加一個簽 token 的小工具與改寫登入：

```js
import jwt from 'jsonwebtoken'

function signToken(userId) {
  return jwt.sign({ sub: String(userId) }, process.env.JWT_SECRET, {
    algorithm: 'HS256',
    expiresIn: '7d',
  })
}

app.post('/auth/login', async (req, res) => {
  const { username, password } = req.body
  const user = await db.query.users.findFirst({ where: eq(users.username, username) })
  if (!user || !(await bcrypt.compare(password ?? '', user.passwordHash))) {
    return res.status(401).json({ error: '帳號或密碼錯誤' })
  }
  res.json({ token: signToken(user.id), user: { id: user.id, username: user.username } })
})
```

註冊同理，回傳 `{ token, user }`。

> 💡 沒有 `/auth/logout` 了——JWT 無狀態，伺服器沒存東西可清。「登出」變成「前端把 token 丟掉」。要伺服器端強制失效是進階主題。
>
> ✅ **檢查點 A**：登入 / 註冊回傳 token。

## 步驟 2：requireAuth 改成驗 token

把 `src/middleware/requireAuth.js` 改成從 header 取 token、驗章：

```js
import jwt from 'jsonwebtoken'

export function requireAuth(req, res, next) {
  const header = req.headers.authorization
  if (!header?.startsWith('Bearer ')) {
    return res.status(401).json({ error: '請帶上 Authorization: Bearer <token>' })
  }
  const token = header.slice('Bearer '.length)
  try {
    // 一定 verify（不能只 decode）；固定 algorithms 防 alg 混淆攻擊
    const payload = jwt.verify(token, process.env.JWT_SECRET, { algorithms: ['HS256'] })
    req.userId = Number(payload.sub)
    next()
  } catch {
    return res.status(401).json({ error: 'token 無效或已過期' })
  }
}
```

> 🧠 為什麼一定要 verify、為什麼要寫 algorithms → [概念卡：JWT 是什麼 § 兩個致命陷阱](../concepts/jwt-是什麼.md)
>
> ✅ **檢查點 B**：requireAuth 改成驗 token。

## 步驟 3：把 todo 路由的使用者來源換掉

M4 用 `req.session.userId`，現在改成 `req.userId`（由 requireAuth 從 token 取出）：

```js
// 例：取得自己的 todos
app.get('/todos', requireAuth, async (req, res) => {
  const rows = await db.query.todos.findMany({
    where: eq(todos.userId, req.userId),   // ← 從 req.session.userId 改成 req.userId
    with: { list: true, todoTags: { with: { tag: true } } },
    orderBy: asc(todos.id),
  })
  res.json(rows.map(shapeTodo))
})
```

其餘路由同樣把 `req.session.userId` 全換成 `req.userId`（見 [完成版 app.js](./完成版/app.js)）。

> ✅ **檢查點 C**：帶 token 能存取自己的 todo，不帶 / 竄改回 401。

## 步驟 4：親眼看 payload 是明文

拿到 token 後，把中間那段（兩個 `.` 之間）base64 解開：

```bash
echo "貼上你的 token" | cut -d. -f2 | base64 -d
# → {"sub":"1","iat":...,"exp":...}
```

你會看到 payload 是**明文**——任何人都讀得到。這就是為什麼**不能把密碼之類的機密放進 JWT**。

> 🧠 簽名只防竄改、不防偷看 → [概念卡：JWT 是什麼](../concepts/jwt-是什麼.md)
>
> ✅ **檢查點 D（完成版）**：你能解出 payload，並理解它沒被加密。
