這章加上「用 Google 登入」。我們**手刻**整個 OAuth 流程（不用第三方 passport 套件），這樣你能看清楚每一步、以及最關鍵的 `state` 防護。

## 步驟 0：取得 Google 憑證

照 [README 的「取得 Google OAuth 憑證」](./README.md#取得-google-oauth-憑證圖文步驟) 拿到用戶端 ID 與密鑰，填進 `.env`：

```
GOOGLE_CLIENT_ID=...apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=...
GOOGLE_REDIRECT_URI=http://localhost:3000/auth/google/callback
```

> ⚠️ `GOOGLE_REDIRECT_URI` 必須和 Google Console 裡「已授權的重新導向 URI」**完全一致**，否則 Google 會拒絕。
>
> ✅ **檢查點 A**：憑證填好。

## 步驟 1：schema 加 googleId，導向 Google

`src/db/schema.js` 的 users 加兩個改動：`passwordHash` 改成可為空（Google 使用者沒密碼）、加 `googleId`：

```js
passwordHash: varchar('password_hash', { length: 255 }),         // 改成可為 null
googleId: varchar('google_id', { length: 255 }).unique(),        // 新增
```

`npm run generate && npm run migrate`。

導向 Google 的路由（產生 state、存 cookie、redirect）：

```js
import crypto from 'node:crypto'
import cookieParser from 'cookie-parser'
app.use(cookieParser())

const GOOGLE_AUTH_URL = 'https://accounts.google.com/o/oauth2/v2/auth'

app.get('/auth/google', (req, res) => {
  const state = crypto.randomBytes(16).toString('hex')
  res.cookie('oauth_state', state, { httpOnly: true, sameSite: 'lax', maxAge: 5 * 60 * 1000 })
  const params = new URLSearchParams({
    client_id: process.env.GOOGLE_CLIENT_ID,
    redirect_uri: process.env.GOOGLE_REDIRECT_URI,
    response_type: 'code',
    scope: 'openid email profile',
    state,
  })
  res.redirect(`${GOOGLE_AUTH_URL}?${params}`)
})
```

> 🧠 state 為什麼能防 CSRF → [概念卡：OAuth 2.0 授權碼流程 § state](../concepts/oauth-流程.md)
>
> ✅ **檢查點 B**：開 `/auth/google` 會被導到 Google，網址帶 `state`。

## 步驟 2：callback——驗 state、換 token、取使用者

```js
const GOOGLE_TOKEN_URL = 'https://oauth2.googleapis.com/token'
const GOOGLE_USERINFO_URL = 'https://www.googleapis.com/oauth2/v2/userinfo'

app.get('/auth/google/callback', async (req, res) => {
  const { code, state } = req.query

  // 防 CSRF：比對 state
  if (!state || state !== req.cookies.oauth_state) {
    return res.status(403).json({ error: 'state 不符（可能是 CSRF）' })
  }
  res.clearCookie('oauth_state')

  // 用 code 換 access token（後端對後端，client_secret 不外露）
  const tokenRes = await fetch(GOOGLE_TOKEN_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams({
      code,
      client_id: process.env.GOOGLE_CLIENT_ID,
      client_secret: process.env.GOOGLE_CLIENT_SECRET,
      redirect_uri: process.env.GOOGLE_REDIRECT_URI,
      grant_type: 'authorization_code',
    }),
  })
  const { access_token } = await tokenRes.json()

  // 用 access token 取使用者資料
  const infoRes = await fetch(GOOGLE_USERINFO_URL, {
    headers: { Authorization: `Bearer ${access_token}` },
  })
  const profile = await infoRes.json()   // { id, email, name, ... }
  // ...下一步用 profile...
})
```

> ✅ **檢查點 C**：state 不符會被擋（403）；相符則能拿到 Google 使用者資料。

## 步驟 3：找/建使用者，簽發自己的 JWT

```js
  let user = await db.query.users.findFirst({ where: eq(users.googleId, profile.id) })
  if (!user) {
    [user] = await db.insert(users)
      .values({ username: profile.email, googleId: profile.id })
      .returning({ id: users.id, username: users.username })
  }

  // 簽發「我們自己的」JWT —— 不要把 user 資料塞進 URL！
  const token = signToken(user.id)
  res.json({ token, user })
```

> ⚠️ 注意：**不要** `res.redirect('/home?user=' + JSON.stringify(user))`。URL 會留在歷史/log/Referer。簽發自己的 JWT，正式環境設成 httpOnly cookie 給前端。
> 🧠 [概念卡：OAuth § 別把使用者資料塞進 URL](../concepts/oauth-流程.md)
>
> ✅ **檢查點 D（完成版）**：完整 Google 登入流程能跑通，拿到自己的 JWT。
