# 工作坊：加上會員登入（Cookie / Session）

到目前為止，todo 是「大家共用」的——任何人都能改任何 todo。這章我們加入會員：要登入才能用，而且只能動自己的 todo。

> 卡住了？對照 [`完成版/`](./完成版/)。

---

## 步驟 1：加 users 表，todos 綁 userId

在 `src/db/schema.js` 加入 users 表，並在 todos 加 `userId`：

```js
export const users = pgTable('users', {
  id: integer().generatedAlwaysAsIdentity().primaryKey(),
  username: varchar({ length: 50 }).notNull().unique(),
  passwordHash: varchar('password_hash', { length: 255 }).notNull(), // 存雜湊，不是明文！
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
})

export const todos = pgTable('todos', {
  // ...原本的欄位...
  userId: integer('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
})
```

並補上關聯（users 有多個 todo、todo 屬於一個 user），然後 `npm run generate && npm run migrate`。

> ✅ **檢查點 A**：users 表建好、todos 有 user_id。

## 步驟 2：設定 session

```bash
npm install express-session bcrypt
```

在 `app.js` 加上 session middleware（放在路由之前）：

```js
import session from 'express-session'

app.use(session({
  secret: process.env.SESSION_SECRET,   // 從環境變數來，絕不硬編！
  resave: false,
  saveUninitialized: false,
  cookie: {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    maxAge: 1000 * 60 * 60 * 24 * 7,
  },
}))
```

`.env` 加一行（用隨機字串）：

```
SESSION_SECRET=用 node -e "console.log(require('crypto').randomBytes(32).toString('hex'))" 產生
```

> 🧠 session 怎麼用 cookie 認人 → [概念卡：Session 機制](../concepts/session-機制.md)
> 🧠 那些 cookie 屬性各防什麼 → [概念卡：Cookie 的安全屬性](../concepts/cookie-安全屬性.md)
>
> ✅ **檢查點 B**：session 設定完成。

## 步驟 3：註冊 / 登入 / 登出

```js
import bcrypt from 'bcrypt'
import { eq } from 'drizzle-orm'
import { users } from './src/db/schema.js'

// 註冊
app.post('/auth/register', async (req, res) => {
  const { username, password } = req.body
  if (typeof username !== 'string' || username.trim().length < 3) {
    return res.status(400).json({ error: 'username 至少 3 個字' })
  }
  if (typeof password !== 'string' || password.length < 6) {
    return res.status(400).json({ error: 'password 至少 6 個字' })
  }
  const existing = await db.query.users.findFirst({ where: eq(users.username, username) })
  if (existing) return res.status(409).json({ error: '這個 username 已被註冊' })

  const passwordHash = await bcrypt.hash(password, 10)   // 雜湊後才存
  const [user] = await db.insert(users)
    .values({ username, passwordHash })
    .returning({ id: users.id, username: users.username })

  req.session.userId = user.id   // ← 登入狀態就靠這行寫進 session
  res.status(201).json(user)
})

// 登入
app.post('/auth/login', async (req, res) => {
  const { username, password } = req.body
  const user = await db.query.users.findFirst({ where: eq(users.username, username) })
  // 帳號不存在或密碼錯，回一樣的訊息（不洩漏哪個帳號存在）
  if (!user || !(await bcrypt.compare(password ?? '', user.passwordHash))) {
    return res.status(401).json({ error: '帳號或密碼錯誤' })
  }
  req.session.userId = user.id
  res.json({ id: user.id, username: user.username })
})

// 登出
app.post('/auth/logout', (req, res) => {
  req.session.destroy(() => {
    res.clearCookie('connect.sid')
    res.status(204).send()
  })
})
```

> 🧠 為什麼存雜湊不是明文、bcrypt 在做什麼 → [概念卡：密碼雜湊與 bcrypt](../concepts/密碼雜湊-bcrypt.md)
>
> ✅ **檢查點 C**：能註冊（密碼雜湊存）、登入、登出。

## 步驟 4：保護路由、把 todo 綁到登入者

建立 `src/middleware/requireAuth.js`：

```js
export function requireAuth(req, res, next) {
  if (!req.session.userId) {
    return res.status(401).json({ error: '請先登入' })
  }
  next()
}
```

把它套到所有 todo 路由，並用 `req.session.userId` 過濾/綁定：

```js
import { and } from 'drizzle-orm'
import { requireAuth } from './src/middleware/requireAuth.js'

// 只看得到自己的
app.get('/todos', requireAuth, async (req, res) => {
  const rows = await db.query.todos.findMany({
    where: eq(todos.userId, req.session.userId),
    with: { list: true, todoTags: { with: { tag: true } } },
    orderBy: asc(todos.id),
  })
  res.json(rows.map(shapeTodo))
})

// 新增時綁上自己的 userId
```
