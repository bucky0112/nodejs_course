# 課堂練習：照三層結構加一個新資源

> 這不是工作坊的延伸，而是**把這堂的核心重點再走一遍**，但這次沒有逐步指引，你得自己寫。
>
> 核心重點：route 只指路、controller 只碰 HTTP、service 負責驗證與資料；檢查不過就拋 `HttpError`，由錯誤處理 middleware 統一回應。

在工作坊完成的 `src/` 結構裡，加上第 5 堂課堂練習的 `/bookmarks` 資源。第 5 堂沒做練習也沒關係，照下面的規格從頭寫。

## 任務

**API 規格**（跟第 5 堂一樣）：

| 方法 | 路徑 | 行為 | 狀態碼 |
|---|---|---|---|
| GET | `/bookmarks` | 回傳全部 | 200 |
| GET | `/bookmarks/:id` | 回傳單筆 | 200 / 404 |
| POST | `/bookmarks` | 新增，需要 `title` 和 `url` | 201 / 400 |
| PATCH | `/bookmarks/:id` | 更新 `title` 或切換 `favorite` | 200 / 400 / 404 |
| DELETE | `/bookmarks/:id` | 刪除 | 204 / 404 |

資料形狀：

```js
{ id: 1, title: 'MDN', url: 'https://developer.mozilla.org', favorite: false, createdAt: '2026-...' }
```

**要新增的檔案**：

- `src/services/bookmarks.service.js`
- `src/controllers/bookmarks.controller.js`
- `src/routes/bookmarks.routes.js`
- 並在 `src/routes/index.js` 掛上 `/bookmarks`

**明確規格**（這幾條就是這堂重點，別漏）：

- `url` 必須以 `http://` 或 `https://` 開頭，否則 400。
- 所有檢查（必填、型別、`url` 格式、找不到）都寫在 **service**，用 `throw new HttpError(...)`。
- controller **不准**出現 `if` 檢查、try/catch，也不准出現 `HttpError`。
- service **不准**出現 `req`、`res`。
- route 檔只有 `Router()` 和路由宣告。
- 「找不到這筆 bookmark」這句錯誤訊息，在整個 service 裡只能出現一次。
- 不准修改 `errorHandler.js`。

> 💡 卡住時回去翻[概念卡：分層架構](../concepts/分層架構.md)的「三層的職責邊界」表格。不要翻 todos 的三個檔案照抄：憑記憶寫，寫不出來才回去看，這樣才練得到。

## 自我檢核

```bash
# 1. 新增 → 201；url 格式錯 → 400
curl -i -X POST http://localhost:3000/bookmarks -H "Content-Type: application/json" -d '{"title":"MDN","url":"https://developer.mozilla.org"}'
curl -i -X POST http://localhost:3000/bookmarks -H "Content-Type: application/json" -d '{"title":"壞網址","url":"mdn"}'

# 2. 壞掉的 JSON → 400（不用改 errorHandler 就該成立）
curl -i -X POST http://localhost:3000/bookmarks -H "Content-Type: application/json" -d '{bad'

# 3. 改不存在的 → 404；favorite 型別錯 → 400
curl -i -X PATCH http://localhost:3000/bookmarks/999 -H "Content-Type: application/json" -d '{"favorite":true}'
curl -i -X PATCH http://localhost:3000/bookmarks/1 -H "Content-Type: application/json" -d '{"favorite":"yes"}'

# 4. 刪除 → 204；再刪一次 → 404
curl -i -X DELETE http://localhost:3000/bookmarks/1
curl -i -X DELETE http://localhost:3000/bookmarks/1
```

- [ ] 2. 所有錯誤回應都是 `{ "error": "..." }`
- [ ] 3. `bookmarks.controller.js` 裡沒有 `if`、try/catch、`HttpError`
- [ ] 4. `bookmarks.service.js` 裡沒有 `req`、`res`
- [ ] 5. `errorHandler.js` 沒有被修改
- [ ] 6. 原本的 `/todos` 全部照常運作
