# Docker 介紹

## 為什麼需要 Docker？

### 開發者的痛點

你可能遇過這些情況：

1. **「我電腦可以跑啊！」**
   - 同事的程式在你電腦跑不起來
   - 部署到伺服器後出現奇怪的錯誤
   - Node.js 版本不同導致問題

2. **環境設定地獄**
   - 安裝 PostgreSQL、Redis、MongoDB...
   - 每台電腦都要重新設定
   - Windows、Mac、Linux 設定方式都不同

3. **專案衝突**
   - 專案 A 需要 Node 18，專案 B 需要 Node 20
   - 資料庫版本互相衝突

## Docker 是什麼？

Docker 是一個**容器化（Containerization）** 平台，讓你可以把應用程式和它需要的環境**打包在一起**。

### 容器 vs 虛擬機

```
┌─────────────────────────────────────────────────┐
│              虛擬機 (VM)                          │
├─────────────────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐  ┌─────────┐         │
│  │  App A  │  │  App B  │  │  App C  │         │
│  ├─────────┤  ├─────────┤  ├─────────┤         │
│  │  完整OS │  │  完整OS │  │  完整OS │  ← 每個都要完整作業系統
│  └─────────┘  └─────────┘  └─────────┘         │
│  ┌─────────────────────────────────────────┐   │
│  │            Hypervisor                    │   │
│  └─────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────┐   │
│  │            主機作業系統                    │   │
│  └─────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│              Docker 容器                         │
├─────────────────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐  ┌─────────┐         │
│  │  App A  │  │  App B  │  │  App C  │         │
│  └─────────┘  └─────────┘  └─────────┘         │
│  ┌─────────────────────────────────────────┐   │
│  │          Docker Engine                   │   │  ← 共享主機核心
│  └─────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────┐   │
│  │            主機作業系統                    │   │
│  └─────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

**容器的優勢：**
- 啟動速度快（秒級 vs 分鐘級）
- 佔用資源少（MB vs GB）
- 更容易管理和遷移

## Docker 核心概念

### 1. Image（映像檔）

- 應用程式的「快照」
- 包含程式碼、執行環境、依賴套件
- 是唯讀的，不會改變
- 類似「類別（Class）」

```bash
# 從 Docker Hub 下載 Node.js 映像檔
docker pull node:20
```

### 2. Container（容器）

- 從 Image 建立的**執行實例**
- 可以啟動、停止、刪除
- 類似「物件（Instance）」

```bash
# 從 node:20 映像檔建立並執行容器
docker run node:20
```

### 3. Dockerfile

- 描述如何建立 Image 的「食譜」
- 定義基礎環境、複製檔案、安裝套件等

```dockerfile
FROM node:20
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
CMD ["node", "index.js"]
```

### 4. Docker Compose

- 同時管理多個容器
- 用一個 YAML 檔案定義整個應用

```yaml
services:
  app:
    build: .
    ports:
      - "3000:3000"
  db:
    image: postgres:16
```

## Docker 在開發中的好處

### 1. 環境一致性
- 開發、測試、正式環境完全相同
- 告別「我電腦可以跑」的問題

### 2. 快速建立開發環境
- 新人加入？一行指令就能啟動整個專案
- 不用花半天安裝資料庫和各種工具

### 3. 隔離性
- 每個專案有自己的環境
- 不同版本的資料庫可以同時存在

### 4. 版本控制
- Dockerfile 可以加入版本控制
- 環境設定也有歷史紀錄

## 使用情境

在這個課程中，我們會學習：

| 情境 | 做法 |
|------|------|
| 開發時需要 PostgreSQL | 用 Docker 啟動資料庫，不用本地安裝 |
| 確保團隊環境一致 | 用 Docker Compose 定義完整開發環境 |
| 部署到雲端 | 打包成 Image，推送到任何支援 Docker 的平台 |

## 小結

Docker 就像是把你的應用程式放進一個「貨櫃」：

- 📦 打包一次，到處執行
- 🚀 秒速啟動，快速開發
- 🔒 環境隔離，互不干擾
- 🤝 團隊共享，環境一致
