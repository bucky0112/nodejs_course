# 課堂練習：把 REST 模式套到一個全新資源

> 這不是工作坊的延伸，而是**把這堂的核心重點再走一遍**，但這次沒有逐步指引，你得自己寫。
>
> 核心重點：路由對應 HTTP 方法、輸入驗證、回正確的狀態碼、找不到回 404。

工作坊帶你做完 `/todos`。現在你要在**同一支 `app.js`** 裡，自己長出一個全新的記憶體資源 `/bookmarks`（網址書籤），把同一套模式親手寫一次。

---

## 任務

**先寫 API 對照表**，再動手寫程式。把下面這張表補完整，放在你的程式碼上方當註解：

| 方法 | 路徑 | 行為 | 狀態碼 |
|---|---|---|---|
| GET | `/bookmarks` | 回傳全部 | ? |
| GET | `/bookmarks/:id` | 回傳單筆 | ? |
| POST | `/bookmarks` | 新增一筆 | ? |
| PATCH | `/bookmarks/:id` | 更新 `title` 或切換 `favorite` | ? |
| DELETE | `/bookmarks/:id` | 刪除一筆 | ? |

**資料形狀**（每筆 bookmark）：

```js
{ id: 1, title: 'MDN', url: 'https://developer.mozilla.org', favorite: false, createdAt: '2026-...' }
```

**明確規格**（這幾條就是這堂重點，別漏）：

- 新增成功回 **201**，不是 200。
- 新增時若 `title` 或 `url` 缺少或是空字串，回 **400** 加一段 JSON 錯誤訊息。
- `url` 必須以 `http://` 或 `https://` 開頭，否則回 **400**。
- `PATCH` 時 `favorite` 若不是布林值，回 **400**。
- 任何 `:id` 找不到，回 **404**，而且要先檢查 404 再檢查 400。
- 刪除成功回 **204**（沒有 body）。
- `id` 用一個遞增的 `nextBookmarkId`，**不要**用 `bookmarks.length + 1`。

> 💡 卡在「為什麼是這個狀態碼」時，回去翻[概念卡：HTTP 狀態碼](../concepts/http-狀態碼.md)。不要翻 `/todos` 的程式碼照抄：憑記憶寫，寫不出來才回去看，這樣才練得到。

## 自我檢核

把伺服器跑起來，用下面的 curl（或 REST Client / Postman）逐條打，對照預期結果。**全過才算完成**：

```bash
# 1. 新增一筆 → 應回 201，body 是剛建立的 bookmark
curl -i -X POST http://localhost:3000/bookmarks -H "Content-Type: application/json" -d '{"title":"MDN","url":"https://developer.mozilla.org"}'

# 2. url 格式錯 → 應回 400
curl -i -X POST http://localhost:3000/bookmarks -H "Content-Type: application/json" -d '{"title":"壞網址","url":"developer.mozilla.org"}'

# 3. 列出全部 → 應回 200 + 陣列
curl -i http://localhost:3000/bookmarks

# 4. 切換 favorite → 應回 200，favorite 變 true
curl -i -X PATCH http://localhost:3000/bookmarks/1 -H "Content-Type: application/json" -d '{"favorite":true}'

# 5. favorite 給字串 → 應回 400
curl -i -X PATCH http://localhost:3000/bookmarks/1 -H "Content-Type: application/json" -d '{"favorite":"yes"}'

# 6. 改不存在的、而且欄位也錯 → 應回 404（不是 400）
curl -i -X PATCH http://localhost:3000/bookmarks/999 -H "Content-Type: application/json" -d '{"favorite":"yes"}'

# 7. 刪除 → 204；再刪一次 → 404
curl -i -X DELETE http://localhost:3000/bookmarks/1
curl -i -X DELETE http://localhost:3000/bookmarks/1
```

- [ ] 1. 新增成功是 `201`（不是 200）
- [ ] 2. 缺欄位或 `url` 格式錯回 `400` 且有 JSON 錯誤訊息
- [ ] 3. 列表回 `200` 且是陣列
- [ ] 4. `PATCH` 切 `favorite` 成功
- [ ] 5. `favorite` 型別錯回 `400`
- [ ] 6. id 不存在時回 `404`，即使欄位也錯
- [ ] 7. 刪除回 `204`、刪不存在的回 `404`
- [ ] 8. 程式碼上方有完整的 API 對照表
